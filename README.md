# One Voting Research Library

Next.js documentation reader untuk empat hasil riset One Voting. Seluruh isi Markdown dirender dari folder `content/` tanpa ringkasan atau pemotongan.

## Run

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Production checks: `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.
